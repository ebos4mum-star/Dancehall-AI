## Known gaps found and closed in this pass

- The server coach and weekly review did not receive wellness data. They now do, through the same shared builder as the device, with per-user scoping, validation, hidden-number handling and fail-closed behaviour.
- Hidden numbers were honoured only by the plateau reply. Recovery, habit and weekly-review replies now honour them too, on the device and the server.
- Wellness cards showed zeros if a read failed. They now show a loading line or a plain error with a retry.
- The four skipped mobile tests are `envLocal.test.ts` (runs only when a developer's git-ignored `.env.local` exists). They pass against a synthetic file.
- `docs/LIVE_INTEGRATION.md` still described the coach and plan as unbuilt; it now matches the code.
