# Content review packs (drafts for qualified reviewers)

**These are preparation material, not content.** Nothing here is published, shown in the app, or approved. Each pack lists scope, what must be decided, structure for the eventual content, sources reviewers should check against current editions, and the checklist from `docs/WEIGHT_MANAGEMENT_EXPANSION.md` section D.6. No claim in these packs is asserted as established fact; every substantive point is a question for the named reviewer. The code gate in `packages/shared/src/evidence.ts` refuses to show any item without an approved, independent review, named sources and compliant language, and the registry is empty.

| Pack                                                     | Reviewer needed                                                                                       |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| [Nutrition and cultural foods](CULTURAL_NUTRITION.md)    | Registered dietitian + cultural reviewers per cuisine                                                 |
| [Strength and low-impact exercise](STRENGTH_TRAINING.md) | Certified strength coach or physiotherapist (and an exercise physiologist)                            |
| [Dancehall and reggae](DANCEHALL_REGGAE.md)              | Exercise professional + cultural practitioners + counsel on rights                                    |
| [Fasting safety (later phase)](FASTING_SAFETY.md)        | Clinician + registered dietitian (+ eating-behaviour expertise). **Fasting is not built or enabled.** |
